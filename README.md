# הכסף שלנו

אפליקציה לטלפון שמציגה במקום אחד את כל הכסף של המשפחה: חשבונות בנק, תיקי השקעות, קופות גמל, קרנות השתלמות, נדל״ן ומשכנתא. האפליקציה רק מציגה. אין בה פעולות כספיות, והיא לא מתחברת לבנקים. את היתרות מזינים ידנית, פעם בחודש.

## איך הנתונים מוגנים

- **המאגר הזה מכיל רק קוד.** אין בו שמות, חשבונות או סכומים.
- **הנתונים עצמם** נמצאים בקובץ אחד במאגר **פרטי** נפרד, `family-money-data`.
- **הקובץ מוצפן בטלפון לפני שהוא עולה.** ההצפנה היא AES-256-GCM, עם מפתח שנגזר מהסיסמה המשפחתית (PBKDF2-SHA-256, 600,000 סבבים). GitHub רואה רק טקסט מוצפן.
- **הסיסמה לא יוצאת מהמכשיר** ולא נשמרת בשום מקום. אין דרך לשחזר אותה, ולכן שומרים אותה במנהל סיסמאות.
- **הגישה למאגר הפרטי היא רק עם טוקן.** טוקן עם הרשאת כתיבה מותקן במכשיר של מי שמעדכן, וטוקן לקריאה בלבד בטלפון השני. בלי טוקן אי אפשר אפילו להוריד את הקובץ המוצפן.
- **גם במכשיר עצמו** הטוקן והעותק השמור של הנתונים מוצפנים בסיסמה.
- **נעילה אוטומטית:** אחרי 5 דקות בלי שימוש, או דקה אחרי שהאפליקציה עוברת לרקע.
- **האתר חסום ברמת הדפדפן** מלשלוח מידע לכל כתובת חוץ מ-`api.github.com`.

## הגדרה ראשונה (פעם אחת, במחשב)

### 1. יצירת טוקן לכתיבה

1. נכנסים ל-<https://github.com/settings/personal-access-tokens/new>.
2. **Token name:** למשל `family-money owner`.
3. **Expiration:** שנה. כשהתוקף פג, יוצרים טוקן חדש ומחברים מחדש.
4. **Repository access:** בוחרים *Only select repositories*, ומשם רק את `family-money-data`.
5. **Permissions:** תחת *Repository permissions*, מגדירים **Contents** כ-*Read and write*.
6. לוחצים *Generate token* ומעתיקים את הטוקן. הוא מתחיל ב-`github_pat_`.

### 2. יצירת קובץ הנתונים

1. פותחים את האפליקציה בכתובת <https://sharonblanaru0.github.io/family-money/>.
2. בוחרים **"זה המכשיר הראשון: יצירת קובץ נתונים"**.
3. מדביקים את הטוקן ובוחרים סיסמה משפחתית, או לוחצים על "הצעת סיסמה חזקה" ושומרים את מה שמוצע.
4. **מבנה התחלתי:** בוחרים את הקובץ `private/family-setup.json` מתיקיית הפרויקט במחשב. הקובץ כולל את בני המשפחה ואת החשבונות, בלי סכומים, והוא לא עולה ל-GitHub.
5. לוחצים **"יצירה והעלאה"**, ובעמוד **עריכה** מזינים את היתרות הראשונות.

## חיבור הטלפונים

### הטלפון של מי שמעדכן

1. במחשב: **הגדרות ← קישור לטלפון שלי**, ושולחים את הקישור לטלפון, למשל בהודעה לעצמכם.
2. בטלפון:
   - **באייפון:** פותחים את הכתובת של האפליקציה בספארי, לוחצים שיתוף ← "הוספה למסך הבית", ופותחים את האפליקציה מהמסך.
   - **באנדרואיד:** פותחים בכרום ובוחרים "התקנת אפליקציה".
3. בוחרים **"חיבור לנתונים קיימים"**, מדביקים את הקישור ומזינים את הסיסמה המשפחתית.

הקישור מוצפן בסיסמה המשפחתית, ולכן אפשר לשלוח אותו בהודעה. בלי הסיסמה אי אפשר להשתמש בו.

### טלפון לצפייה בלבד

1. יוצרים טוקן נוסף, כמו בשלב 1, אבל עם **Contents: Read-only**.
2. במחשב: **הגדרות ← קישור לטלפון לצפייה בלבד**, ומדביקים את הטוקן החדש. הוא לא נשמר במחשב.
3. שולחים את הקישור לטלפון וממשיכים כמו בטלפון הקודם.

## העדכון החודשי

1. **עריכה ← יתרות:** מעתיקים את היתרות מהאתרים. מה שלא ממלאים נשאר עם הערך האחרון.
2. לוחצים **"שמירה ופרסום"**. הטלפונים האחרים יקבלו את העדכון בפתיחה הבאה.
3. **חלונית הסטטוס בעמוד הסקירה:**
   - ירוקה: כל החשבונות עודכנו ב-45 הימים האחרונים.
   - צהובה: חשבון כלשהו לא עודכן יותר מ-45 יום. לנדל״ן הסף הוא שנה.

בלשונית **עריכה ← משפחה וחשבונות** מוסיפים, משנים ומוחקים ילדים, חשבונות ונכסי נדל״ן.

|---|---|

| "הסיסמה של הנתונים שונתה במכשיר אחר" | יוצרים קישור צירוף חדש במכשיר הראשי ומחברים איתו. |

| אין אינטרנט | האפליקציה מציגה את העותק השמור האחרון, ומפרסמת את השינויים כשהחיבור חוזר. |

## מבנה הקוד

- `index.html`, `styles.css`: המעטפת והעיצוב.
- `js/crypto.js`: ההצפנה.
- `js/github.js`: קריאה וכתיבה של הקובץ המוצפן.
- `js/store.js`: אחסון מוצפן במכשיר.
- `js/model.js`: החישובים.
- `js/charts.js`: הגרפים.
- `js/app.js`: המסכים.
- `sw.js`: עבודה בלי חיבור.
- `tools/make_icons.py`: יצירת האייקונים.

אין שלב build ואין ספריות חיצוניות. להרצה מקומית מריצים:

```
python -m http.server 8000
```

ופותחים את <http://localhost:8000>.
